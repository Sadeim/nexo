# Public downloads

Publicly served at `https://nexobarbers.com/downloads/`.

Currently used for **Nexo POS APK** OTA updates. Filenames should follow the
convention `nexo-pos-<versionName>.apk`, e.g. `nexo-pos-1.0.1.apk`.

APK binaries are gitignored — upload them directly to the server via SCP or
hPanel File Manager (see `apps/nexo_pos/RELEASE.md`).
